# 종소리가 닿는 곳까지 — 현재 상태

> 이 문서는 **상담용 요약본**입니다. 저장소를 보지 않은 사람이 읽고 조언할 수 있게
> 게임의 내용과 지금까지 만들어진 것, 열려 있는 문제를 정리했습니다.
> 마지막 갱신: 2026-09-28

---

## 한 줄

어둠에 잠긴 중세 섬에서, **등불을 들고 굳어버린 사람을 깨워 종탑까지 데려가 종을 울리면
그 구역이 영구히 밝아지는** 2.5D 탑다운 RPG. 구한 사람은 첫 마을에 자리를 잡고
자기 직업으로 플레이어를 강하게 만든다.

## 프로젝트 맥락

- **1인 개발.** 대학 소프트웨어공학 수업 과제로 시작했고, 학기 이후에도 계속 갈 장기 프로젝트
- **C++ / OpenGL 3.3 Core Profile / GLUT.** 엔진 없이 직접 만든다
- **크로스 플랫폼**: macOS(Makefile) + Windows(Visual Studio). 둘 다 빌드된다
- 약 10,400줄, 커밋 7개
- 외부 라이브러리 없음. 시스템 프레임워크만 쓴다(OpenGL, GLUT, CoreText/GDI)

## 게임 컨셉

### 톤과 배경

역병이 휩쓸고 간 중세의 섬. 세상은 검은 연기에 덮여 있고, 사람들은 어둠에 사로잡혀
그 자리에 굳어 있다. **암울하지만 가끔 희망이 보이는** 분위기를 목표로 한다.

### 핵심 규칙 — 빛

이 게임의 모든 것이 빛 하나로 돌아간다.

- **배경색 자체가 어둠이다.** 어둠을 덮어 그리지 않고, 밝은 곳만 밝기를 곱해 그린다
- **구조물(집·나무)은 연기 너머로 희미하게 보이지만**, 오브젝트·적·사람은 불을 비춰야 드러난다
- **등불은 휴대품**이고 기름이 줄면 반경이 준다. **화톳불은 설치형 소모품**
- 지나간 자리에 **빛의 발자국**이 남았다가 25초에 걸쳐 식는다

### 한 바퀴 (핵심 루프)

```
어두운 마을 도착
  → 까마귀 소리로 적의 출현을 안다
  → 몬스터를 쓰러뜨리며 영혼석을 줍는다 (레벨업)
  → 굳은 사람을 찾는다 (연기 너머로 검게 보인다)
  → 등불을 2초간 비춰 생기를 되돌린다
  → 말을 건다 → 종탑 위치를 알려주고 따라나선다
  → 종탑지기(보스)를 쓰러뜨린다
  → 둘이 함께 종을 울린다 (4.5초간 Space 유지)
  → 구역이 영구히 밝아지고, 그 사람은 첫 마을에 자리를 잡는다
  → 그 사람의 직업에 맞는 영구 강화를 받는다
```

### 무엇에 대한 게임인가

**강해지는 것이 곧 누구를 구했는가**가 되게 하는 것이 설계 의도다. 레벨은 전투로 오르지만,
되돌릴 수 없고 누적되는 힘은 사람을 구해야만 얻는다. 첫 마을이 차오르는 것이
지금까지 해낸 일의 크기다.

## 기술 구조

### 세계

```
타일 32px → 청크 16x16 타일 → 마을(구역) 3x3 청크 = 48타일 = 1536px
```

- 청크는 **좌표 + 씨앗만으로 결정**된다. 되돌아와도 지형이 같고, 저장할 것이 씨앗 하나다
- 모든 청크에 십자 흙길이 있어 **길이 반드시 이어진다**
- 생성 마지막에 길에서 플러드필을 돌려 **닿지 않는 칸을 막은 나무를 벤다** → 갇히지 않는다
- 바뀌는 것(종을 울렸나 / 사람을 깨웠나)만 따로 기록한다

## 지금 열려 있는 문제

### 1. F키가 "안 먹는" 것처럼 느껴진다 ← 가장 시급

첫 마을을 안전지대로 만들면서 **시작 지점에 적이 하나도 없어졌다.** 적이 없으면 자동 조준이
과녁을 못 잡고 불씨가 엉뚱한 방향으로 날아가 사라진다. 코드는 정상이고 발사도 된다.

거기에 **사거리 270px이 화면 절반(480px)보다 짧아서**, 화면에 보이는 적을 못 때린다.
사거리 밖일 때 실패했다는 신호도 전혀 없다.

검토 중인 선택지: 안전 반경 축소 / 가장자리에 약한 적 / 광장에 허수아비 / 사거리 상향

### 2. 성능 — 도형 개수

드로우 콜은 모아 그리기로 해결됐지만 **도형 개수 11,000개는 그대로**다. 숲 띠를 넣으면서
두 배가 됐다. 화면 밖 컬링과 LOD(어두우면 나무를 덩어리 하나로)가 후보.
밝기 기반 컬링은 **불가** — 구조물은 어두워도 34%로 보이도록 설계돼 있어서 사라져 버린다.

### 3. 전투 밸런스 미검증

종탑지기 체력 520 vs 1레벨 화력이 맞는지 확인되지 않았다. 동행자는 아직 **함께 싸우지 않는다**
(기획서에는 있는데 미구현).

### 4. 되찾은 NPC의 처리

지금은 종을 울리는 순간 첫 마을에 **즉시 나타난다**(걸어가지 않음). 그런데 동행자는
종탑에 남아 종을 울리는 것으로 되어 있어서, **같은 사람이 두 곳에 있는 셈**이다.
